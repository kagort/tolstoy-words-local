# Английский язык: оценка трудоёмкости и ресурсов (2026-11-02)

Статус: **только оценка, код не менялся.** Цель — весь функционал приложения на английских текстах
(интерфейс остаётся русским).

## Что в приложении зависит от языка
Синтаксический слой построен на Universal Dependencies (UD) — разметке, общей для языков, поэтому значительная часть
анализа переносится без переделки. Языковые места:

| Часть | Сейчас (русский) | Для английского | Сложность |
|---|---|---|---|
| Сегментация на предложения и токены | razdel (только русский) + пост-правила (`segment.py`) | токенизатор Stanza en (сокращения Mr., e.g., апострофы don't) | средняя |
| Быстрый разбор (ступень 1) | Natasha (только русский) | UDPipe 1 English-EWT (UD, ~16 МБ, очень быстрый) или сразу Stanza | средняя |
| Точный разбор (ступень 2) | Stanza ru (SynTagRus) | Stanza en (EWT/GUM), та же библиотека | низкая |
| Леммы и формы слов | pymorphy3 (`fix_lemma`, `word_forms` для словаря «по формам», `phrases`) | леммы Stanza; формы — lemminflect или правила (go → goes, went, gone) | средняя |
| Члены предложения и связи (`syntax.py`, ~780 строк) | правила UD + русские: падеж «у+Gen», деепричастия, причастные обороты, «который», нулевая связка | UD-правила те же; английские: who/which/that, -ing и to-инфинитив, связка be, фразовые глаголы (`compound:prt`), притяжательный 's, «предлог + падеж» → «предлог» | **высокая** — главная работа |
| Подписи ролей | школьная грамматика русского | те же русские названия (подлежащее, сказуемое…) с метками UD | низкая |
| Стоп-слова, служебные слова для стилометрии | `stopwords_ru.txt` | английский список (NLTK / spaCy) | низкая |
| Имена (NER) | Natasha NER, склонение имён, слияние «Андрей / Андрея» | Stanza en NER (OntoNotes, 18 классов); склонения нет — проще | средняя |
| География | газеттир GeoNames на русском | английские названия GeoNames (те же объекты) | низкая–средняя |
| Семантика (похожие слова, карта словаря, значения) | navec (русские векторы, ~50 МБ) | GloVe 100d (~130 МБ сжатый) или fastText-en уменьшенный | средняя |
| Однокоренные слова | русские правила словообразования | английские суффиксы/приставки (happy → happiness, unhappy) | средняя |
| Признаки машинного текста | маркеры на русском (`ai_markers_ru.txt`) | английский список маркеров | низкая (или выключить) |
| Ключевые слова, коллокации, темы, карта текста, дашборд, отчёт, портрет | от языка не зависят (леммы + статистика) | работают сразу после разбора | — |

## Изменения в данных и интерфейсе
- Поле «язык» у текста (определяется автоматически при загрузке, можно поправить) и у словаря.
- Корпус — тексты одного языка (или предупреждение при смешении); в панели выбора — фильтр «язык».
- Словарь сопоставляется только с текстами своего языка.
- Справка: раздел о различиях анализа для английского.

## Трудоёмкость
| Этап | Дни |
|---|---|
| Язык у текста/словаря/корпуса, выбор парсера по языку, загрузка моделей en | 2–3 |
| Сегментация, леммы, формы слов, стоп-слова, части речи | 1–2 |
| Синтаксический слой для английского + проверка на размеченных предложениях (UD EWT) | 3–5 |
| Имена (NER), география | 2–3 |
| Семантика, однокоренные слова, стилометрия, признаки ИИ | 2–3 |
| Интерфейс: язык в загрузке, корпусах, словарях, панели выбора; справка | 2 |
| Демо-корпус на английском, тесты, документация | 2 |
| **Итого** | **≈ 14–20 рабочих дней (3–4 недели)** |

Можно по частям: **этап 1 (≈ 1–1,5 недели)** — разбор, частоты, конкорданс, коллокации, ключевые слова, портрет,
отчёт, дашборд, профиль слова с базовыми UD-правилами; **этап 2** — английские синтаксические правила, имена,
география, семантика, однокоренные, признаки ИИ.

## Ресурсы сервера
| Ресурс | Сейчас | С английским |
|---|---|---|
| Диск (модели) | Stanza ru ~0,6 ГБ + Natasha, navec ~0,1 ГБ | + Stanza en ~0,5–0,7 ГБ (с NER) + UDPipe ~16 МБ + векторы ~0,15–0,3 ГБ → **+≈1 ГБ** |
| Память обработчика | ~1,5–2 ГБ (Stanza ru) | обе модели в одном обработчике — **~3–3,5 ГБ**; или отдельный обработчик для английского (~1,5 ГБ) |
| Память веб-сервера | navec для семантики | + векторы en (~0,3–0,5 ГБ в памяти) |
| Скорость разбора | — | Stanza en на CPU сопоставима с ru (английские предложения короче, морфология проще) |
| Сервер | 4 ГБ ОЗУ хватает впритык | рекомендую **8 ГБ ОЗУ**, 2–4 ядра, +2 ГБ диска |

Риски: английская модель Stanza скачивается с HuggingFace (у вас при сборке бывали обрывы — зеркало `HF_ENDPOINT`
уже поддерживается); синтаксические правила требуют проверки на настоящих английских деревьях (в среде разработки
Stanza недоступна — проверка на UD EWT и на ваших текстах).
