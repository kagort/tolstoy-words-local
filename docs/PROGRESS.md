## Профиль и договорённости

- **Опыт:** Python — пишу медленно, синтаксис чувствую слабо; SQL, Git, Docker, Flask/FastAPI — пробовал(а) в вайб-кодинг-проектах.
- **Система:** Windows, Docker Desktop установлен.
- **Время:** ~6 часов в неделю (≈ 2–3 занятия по 2–3 часа).
- **Работаю один(одна).** Ветки и PR используем всё равно — это страховка от потери работы.
- **Режим обучения — постепенная передача:**
  1. *Я пишу — объясняю каждую строку* → вы запускаете у себя.
  2. *Я пишу каркас — вы дописываете 3–10 строк* по подсказке.
  3. *Вы пишете — я делаю ревью.*

  Начинаем с режима 1, но **в каждом занятии есть хотя бы одна маленькая правка, которую делаете вы сами**. Переход к следующему режиму — когда вы готовы, без спешки.
- **Правило занятия:** результат каждого шага проверяется запуском у вас на машине. Ошибки — это нормально, их разбор и есть обучение.

## Шпаргалка по Git

Обычный цикл одного занятия:

```powershell
git checkout master            # перейти на чистовик
git pull origin master         # скачать свежий master с GitHub и влить в текущую ветку
git checkout -b lesson-X-Y     # создать ветку-черновик и перейти в неё
# ... правки в VS Code, Ctrl+S ...
git status                     # что изменено? в какой я ветке?
git diff                       # ЧТО именно изменено? строки с «-» там, где ничего не удалял(а) — стоп!
git add путь/к/файлу           # конкретные файлы, не «.»
git commit -m "что и зачем"    # точка сохранения
git push -u origin lesson-X-Y  # отправить ветку на GitHub (-u только в первый раз)
# GitHub: Pull request → Files changed (проверить) → Merge
git checkout master
git pull origin master
```

Страховка:
- `git restore файл` — отменить незакоммиченные правки в файле (безвозвратно).
- `Ctrl+Z` в VS Code — отменить последнее действие в редакторе.
- Перед вводом команды проверить, что курсор мигает **в терминале**, а не в редакторе.
