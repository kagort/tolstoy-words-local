# Французский язык: оценка трудоёмкости и ресурсов (2026-11-15)

Статус: **только оценка, код не менялся.** Цель — весь функционал приложения на французских текстах (интерфейс
остаётся русским). Читать вместе с `ENGLISH_ESTIMATE.md`: общая часть (язык у текста, словаря и корпуса, выбор
парсера по языку) делается один раз для любого второго языка.

## Чем французский отличается от английского
| Часть | Для французского | Сложность |
|---|---|---|
| Точный разбор | Stanza fr (UD French-GSD): токенизация, морфология, леммы, синтаксис; качество высокое | низкая |
| **Слитные формы** | `du` = de + le, `au` = à + le, `des`, `aux`: Stanza раскладывает одно слово на два синтаксических (MWT). Сейчас приложение считает «один токен текста = одно слово разбора» (подсветка в конкордансе, позиции слов) — нужна поддержка «слово внутри токена» | **высокая** — главное отличие от английского |
| Элизия и апостроф | `l'homme`, `qu'il`, `j'ai`, `aujourd'hui`: токенизатор Stanza fr (свой razdel — только русский) | средняя |
| Быстрый разбор (ступень 1) | UDPipe French-GSD (~20 МБ) или сразу Stanza | средняя |
| Леммы и формы слов | леммы Stanza; словарь «по формам» — нужен морфологический словарь (Lefff / UniMorph, ~10–30 МБ): у глагола до 40–50 форм, вручную правилами не покрыть | средняя |
| Синтаксические правила (`syntax.py`) | UD-правила те же; французские: клитики (`je le lui donne`), `qui / que / dont / où`, причастие настоящего времени и герундий (`en chantant`), связка `être`, пассив и возвратные глаголы (`se`), составное отрицание `ne … pas` | высокая — как для английского |
| Имена (NER) | Stanza fr NER — 4 класса (персона, место, организация, прочее); склонения нет | средняя |
| География | французские названия GeoNames (те же объекты) | низкая–средняя |
| Семантика | векторы fastText fr, урезанные до ~200 тыс. слов (~250–400 МБ) | средняя |
| Однокоренные слова | французские суффиксы и приставки (`-tion`, `-ment`, `-eur`, `re-`, `in-`) | средняя |
| Стоп-слова, служебные слова стилометрии | готовые списки | низкая |
| Признаки машинного текста | французский список маркеров (или выключить) | низкая |
| Частоты, конкорданс, коллокации, ключевые слова, темы, карта текста, пунктуация, отчёт, дашборд, профиль сочетания | от языка не зависят | — |

Пунктуация: во французском пробел перед `; : ! ?` и кавычки `« … »` с пробелами — на подсчёт знаков не влияет,
но нормализация текста не должна эти пробелы «исправлять».

## Трудоёмкость
| Вариант | Дни |
|---|---|
| **Французский первым вторым языком** (вся общая часть + французская) | **≈ 15–21 рабочий день** (3–4 недели) |
| **Французский после английского** (общая часть уже есть) | **≈ 8–11 дней** |
| Английский + французский вместе | ≈ 22–30 дней (общая часть — один раз) |

Французская часть по этапам: слитные формы и элизия — 2–3 дня; леммы, формы слов, стоп-слова — 1–2; синтаксические
правила и проверка на размеченных предложениях (UD French-GSD) — 3–4; имена и география — 1–2; семантика,
однокоренные, стилометрия — 1–2; демо-корпус, тесты, документация — 1.

Можно в два шага: **шаг 1 (≈ 1–1,5 недели после общей части)** — разбор, частоты, конкорданс, коллокации, ключевые
слова, пунктуация, отчёт, портрет слова с базовыми правилами; **шаг 2** — французские синтаксические правила, имена,
география, семантика.

## Ресурсы сервера
| Ресурс | Только русский | + французский | + английский и французский |
|---|---|---|---|
| Диск (модели) | ~0,7 ГБ | +≈1 ГБ (Stanza fr с NER ~0,6 ГБ, UDPipe, векторы, словарь форм) | +≈2 ГБ |
| Память обработчика | 1,5–2 ГБ | ~3–3,5 ГБ (две модели) | ~4,5–5 ГБ, или отдельный обработчик на язык (~1,5–2 ГБ каждый) |
| Память веб-сервера | векторы ru | +0,3–0,5 ГБ | +0,6–1 ГБ |
| Сервер | 4 ГБ ОЗУ впритык | **8 ГБ ОЗУ**, 2–4 ядра | **12–16 ГБ ОЗУ**, 4 ядра |

Модели скачиваются один раз; для сервера без интернета — добавляются в пакет для флешки (`offline-pack.sh
--with-models`). Скорость разбора Stanza fr на CPU сопоставима с русской.

## Риски
- Слитные формы (`du`, `au`) затрагивают хранение токенов — менять аккуратно, с проверкой, что русские тексты
  разбираются побайтно как прежде.
- Stanza в среде разработки недоступна: правила проверять на корпусе UD French-GSD и на текстах пользователя.
- Старые французские тексты (до XIX в.): орфография и леммы хуже — как с дореформенной русской.
